Every session you log gets appended to a Google Sheet automatically. Your data lives in your Google account — viewable, shareable, and permanent regardless of what happens to this app.
One-time setup
Takes about 5 minutes. You'll create a free Google Apps Script that acts as a bridge between this app and your Sheet.
1
Go to sheets.google.com and create a new spreadsheet. Name it Training Tracker.
2
Click Extensions → Apps Script. Delete existing code and paste the script below. Click Save, then Deploy → New deployment. Set type to Web app, execute as Me, access to Anyone. Copy the Web App URL.
3
Paste the Web App URL below and click Connect.
function doPost(e) { var ss = SpreadsheetApp.getActiveSpreadsheet(); var sheet = ss.getSheetByName('Sessions') || ss.insertSheet('Sessions'); var data = JSON.parse(e.postData.contents); if (sheet.getLastRow() === 0) { sheet.appendRow(data.headers); } sheet.appendRow(data.row); return ContentService.createTextOutput(JSON.stringify({status:'ok'})) .setMimeType(ContentService.MimeType.JSON); }
